# P10 — CLI i18n structure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adding a CLI language becomes one catalog data file plus one registry line, with no Go edits by a translator,
while the en/zh output stays byte-for-byte unchanged.

**Architecture:** The two Go map catalogs (`internal/i18n/catalog_{en,zh}.go`, ~1720 entries each) become embedded YAML
files `internal/i18n/locales/<lang>.yaml`, read by a strict loader. Languages are declared once in a registry
(`internal/i18n/languages.go`); everything that today asks "is it zh?" asks the registry or the catalog instead. The
`internal/msgid` message constants are generated from `locales/en.yaml` (`cmd/gen-msgid`, checked by `make lint`), so a
new message is written in the catalogs only. Message IDs whose names no longer describe their text are renamed with an
AST tool. Every i18n guard iterates the registry.

**Tech Stack:** Go 1.22, `gopkg.in/yaml.v3` (already a dependency), `embed`, `go/ast` + `go/parser` for the tools, cobra
v1.10.2.

**Spec:** the P10 row of `docs/superpowers/plans/2026-09-26-three-layer-refactor-roadmap.md` (quoted verbatim below — it is
the whole spec for this phase).

> Restructure the CLI's i18n so another language or a non-programmer translator needs no Go edits (decided 2026-09-28
> after the P8 bilingual audit; the en/zh design itself is sound and stays): catalogs move from Go maps
> (`catalog_{en,zh}.go`, ~5600 lines) to one embedded data file per language; languages are registered in one place
> instead of `if l == ZH` in `i18n.go`, the hard-coded list in `resolve.go` and the zh check in `skills/install.go`; the
> Chinese cobra usage template in `root.go` moves into the catalogs; `internal/msgid` constants are generated from the
> English catalog so a new message is written in the catalogs only; message IDs whose names no longer match their text
> (named after the original English sentence, e.g. `CliUpSecretsTheConfigInBrickkitYaml`) are renamed; every i18n guard
> runs over all registered languages. Plural forms beyond one/other (ru, pl, ar) only if such a language is actually
> added. Runs after P9; move it before P9 if a third language is planned soon.
>
> Exit: Adding a language = one catalog file + one registry line; `make lint` and `make test-all` green; the en/zh output
> is byte-for-byte unchanged.

## Global Constraints

- **Output is byte-for-byte unchanged** in en and zh: every message text, every `--help`, the cobra templates. Task 1
  freezes it; every later task keeps those goldens green without regenerating them. The only task allowed to change a
  golden is none — a golden diff is a bug.
- **No new Go dependency.** YAML goes through `gopkg.in/yaml.v3`, already in `go.mod`.
- **Catalog value style:** every value in `locales/*.yaml` is a double-quoted scalar or a literal block scalar (`|` /
  `|-` / `|+`); the loader rejects any other style (plain, single-quoted, folded) with the file, line and key. Keys are
  unique; a duplicate key is an error naming both lines.
- **English is the source language.** `locales/en.yaml` declares every key; every other catalog has exactly the same
  keys, except `<key>.one` plural entries, which a language writes only if it distinguishes singular (as today).
- **Only one/other plural forms** (the existing `msgid.PluralOneSuffix` mechanism). No CLDR plural rules in this phase.
- **Production code outside `internal/i18n` never branches on a specific language** (`i18n.ZH`, `i18n.Lang("zh")`, a
  `"zh"` literal compared with a language). A guard test enforces it.
- **Startup budget:** loading the current language's catalog adds at most 10 ms to a CLI invocation
  (`BenchmarkLoadCatalog` in Task 4; measured on the developer machine, recorded in the ledger).
- Comments in Go code are written in Chinese, like the rest of the repository; YAML catalog header comments are in the
  catalog's own language.
- Each task ends with `go build ./... && go vet ./...`, `.tools/bin/golangci-lint run ./...`, and
  `go test ./internal/... ./tests/...` with the real exit code checked (never through `| grep`). Tests that walk the
  whole source tree or use reflection run under
  `systemd-run --user --scope -q -p MemoryMax=8G -p MemorySwapMax=0`.
- Commit after each task (subject `<type>: <what changed>`), ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Work on `main`, no worktree.
- Out of scope: the documentation trees `docs/{en,zh}` and their guards (those are docs, not CLI i18n); the skill assets'
  own content; market-server messages.

## Review Focus

1. **A catalog value YAML would reinterpret** — a plain `yes`, a leading `%` or `@`, `: ` inside the text, leading or
   trailing spaces, a trailing `\n`, a tab, `#` — a translator writing it naturally must get either exactly that text or
   a load error naming the line, never a silently different string. (Task 3, `TestParseCatalogPreservesTextExactly` and
   `TestParseCatalogRejectsAmbiguousStyles`.)
2. **A duplicate key in a catalog file** — the second copy must not silently win. (Task 3,
   `TestParseCatalogRejectsDuplicateKeys`.)
3. **Placeholders that differ between languages** — `%[2]s` used in zh but absent from en, or `%[1]d` in one and `%[1]s`
   in the other — must fail a guard, not surface as `%!s(MISSING)` at run time. (Task 9, `TestCatalogVerbsMatchSource`.)
4. **A language registered without skill assets** — `brickkit init` in that language must install the English skill
   assets and record `en` in `skills.lock`, not fail or install nothing. (Task 8,
   `TestAssetsFallBackToSourceLanguage`.)
5. **The generated msgid file going stale** — adding a key to `en.yaml` and forgetting `make generate-msgid` must fail
   `make lint`, and a key whose Go name would collide with another must fail generation. (Task 5,
   `TestGeneratedMsgidIsCurrent`, `TestGoNamesAreUnique` in `internal/msgid/msgidgen`.)

```go
func TestHelpGolden(t *testing.T) {
	for _, lang := range []i18n.Lang{i18n.EN, i18n.ZH} {
		t.Setenv(i18n.EnvLang, string(lang))
		var paths [][]string
		var walk func(c *cobra.Command, path []string)
		walk = func(c *cobra.Command, path []string) {
			paths = append(paths, path)
			for _, sub := range c.Commands() {
				walk(sub, append(append([]string(nil), path...), sub.Name()))
			}
		}
		root := NewRootCommand(NewOptions())
		// cobra 在执行时才给英文命令树补上 help 与 completion；这里先补上，两种语言列出的路径才一样
		root.InitDefaultHelpCmd()
		root.InitDefaultCompletionCmd()
		walk(root, nil)
		for _, path := range paths {
			r := runIn(t, t.TempDir(), append(append([]string(nil), path...), "--help")...)
			name := strings.Join(append([]string{"root"}, path...), "_") + ".txt"
			file := filepath.Join("testdata", "help", string(lang), name)
			if *updateHelp {
				require.NoError(t, os.MkdirAll(filepath.Dir(file), 0o755))
				require.NoError(t, os.WriteFile(file, []byte(r.stdout), 0o644))
				continue
			}
			want, err := os.ReadFile(file)
			require.NoError(t, err, "没有基线：%s", file)
			require.Equal(t, string(want), r.stdout, "%s %v --help 变了", lang, path)
		}
	}
}
```

```go
package i18n

// 本文件是 CLI 支持哪些语言的唯一登记处。加一种语言 = 在 registry 里加一行，
// 再放一份 locales/<代码>.yaml（Task 3 起）。别处一律从这里推出语言列表，不写死。

// Lang 是语言代码（BRICKKIT_LANG、brickkit lang set 的取值）。
type Lang string

const (
	EN Lang = "en"
	ZH Lang = "zh"
)

// Language 是登记的一种语言。
type Language struct {
	Code Lang
}

// registry 按展示顺序列出全部语言；第一项是源语言：每个 key 先在它的目录里声明，
// 其余语言的目录与它逐 key 对应。
var registry = []Language{
	{Code: EN},
	{Code: ZH},
}

// Source 返回源语言。
func Source() Lang { return registry[0].Code }

// registered 报告 l 是否是登记过的语言。
func registered(l Lang) bool {
	for _, lang := range registry {
		if lang.Code == l {
			return true
		}
	}
	return false
}
```

In `i18n.go`, delete the `type Lang` and the `EN`/`ZH` const block (now in `languages.go`), and replace `catalogFor`:

```go
// catalogs 是每种登记语言的目录。
var catalogs = map[Lang]map[string]string{EN: en, ZH: zh}

// catalogFor 返回 l 的目录；没登记的语言用源语言的目录（与重构前一样：未知语言就是英文）。
func catalogFor(l Lang) map[string]string {
	if c, ok := catalogs[l]; ok && registered(l) {
		return c
	}
	return catalogs[Source()]
}
```

In `resolve.go`, replace `ParseLang` and `SupportedLangs`:

```go
// ParseLang 校验字符串是否是已登记的语言，容忍大小写与前后空白。
func ParseLang(s string) (Lang, bool) {
	l := Lang(strings.ToLower(strings.TrimSpace(s)))
	if registered(l) {
		return l, true
	}
	return "", false
}

// SupportedLangs 返回全部已登记语言，顺序即 registry 的顺序。
func SupportedLangs() []Lang {
	out := make([]Lang, len(registry))
	for i, l := range registry {
		out[i] = l.Code
	}
	return out
}
```

`Resolve()`'s final `return EN, SourceDefault` becomes `return Source(), SourceDefault`.

```go
package i18n

import (
	"fmt"

	"gopkg.in/yaml.v3"
)

// CatalogError 指出目录文件里有问题的那一条。
type CatalogError struct {
	File   string
	Line   int
	Key    string
	Reason string
}

func (e *CatalogError) Error() string {
	if e.Key == "" {
		return fmt.Sprintf("%s:%d: %s", e.File, e.Line, e.Reason)
	}
	return fmt.Sprintf("%s:%d: %s: %s", e.File, e.Line, e.Key, e.Reason)
}

// parseCatalog 读一份目录文件：顶层是 key: 文案 的映射。
//
// 文案只接受双引号纯量与字面块（| |- |+）：其余写法会被 YAML 悄悄改写
// （裸写的 yes、首尾空格、折行），译者看到的与程序拿到的就不是同一句话。
// 同一个 key 出现两次是错误，不是"后写的赢"。
func parseCatalog(data []byte, file string) ([]string, map[string]string, error) {
	var doc yaml.Node
	if err := yaml.Unmarshal(data, &doc); err != nil {
		return nil, nil, &CatalogError{File: file, Line: 1, Reason: err.Error()}
	}
	if len(doc.Content) == 0 {
		return nil, map[string]string{}, nil
	}
	root := doc.Content[0]
	if root.Kind != yaml.MappingNode {
		return nil, nil, &CatalogError{File: file, Line: root.Line, Reason: "the file must be a mapping of key: text"}
	}
	keys := make([]string, 0, len(root.Content)/2)
	texts := make(map[string]string, len(root.Content)/2)
	firstLine := map[string]int{}
	for i := 0; i+1 < len(root.Content); i += 2 {
		k, v := root.Content[i], root.Content[i+1]
		if first, dup := firstLine[k.Value]; dup {
			return nil, nil, &CatalogError{File: file, Line: k.Line, Key: k.Value, Reason: fmt.Sprintf("duplicate key (first on line %d)", first)}
		}
		firstLine[k.Value] = k.Line
		if v.Kind != yaml.ScalarNode || (v.Style != yaml.DoubleQuotedStyle && v.Style != yaml.LiteralStyle) {
			return nil, nil, &CatalogError{File: file, Line: k.Line, Key: k.Value, Reason: `write the text in double quotes ("…") or as a literal block (|)`}
		}
		keys = append(keys, k.Value)
		texts[k.Value] = v.Value
	}
	return keys, texts, nil
}
```

```go
	entryRe = regexp.MustCompile(`^\s*msgid\.(\w+)( \+ msgid\.PluralOneSuffix)?:\s*("(?:[^"\\]|\\.)*"),?\s*$`)
	constRe = regexp.MustCompile(`(?m)^\s*(\w+)\s*=\s*"([^"]+)"`)

var headers = map[string]string{
	"en": "# BrickKit CLI messages — English. This is the source catalog: every key is declared here first,\n" +
		"# and every other locales/<lang>.yaml has exactly the same keys.\n" +
		"# Each text is written in double quotes (\"…\") or as a literal block (|); %[1]s, %[2]d… are the\n" +
		"# message's arguments, by position. After adding or removing a key here, run: make generate-msgid\n",
	"zh": "# BrickKit CLI 消息——中文。key 与 en.yaml 一一对应；en.yaml 里没有的 key 不要写。\n" +
		"# 文案写在双引号（\"…\"）里，或者写成字面块（|）；%[1]s、%[2]d… 是按位置排的参数，与英文用同一组。\n",

func main() {
	keys, err := constants()
	if err == nil {
		for _, lang := range os.Args[1:] {
			if err = convert(lang, keys); err != nil {
				break
			}
		}
	}
	if err != nil {
		fmt.Fprintln(os.Stderr, "tocatalog:", err)
		os.Exit(1)
	}

// constants 读 internal/msgid 下的常量：Go 名 → key。
func constants() (map[string]string, error) {
	files, err := filepath.Glob("internal/msgid/*.go")
	if err != nil {
		return nil, err
	}
	out := map[string]string{}
	for _, f := range files {
		body, err := os.ReadFile(f)
		if err != nil {
			return nil, err
		}
		for _, m := range constRe.FindAllStringSubmatch(string(body), -1) {
			out[m[1]] = m[2]
		}
	}
	return out, nil
}

func convert(lang string, keys map[string]string) error {
	body, err := os.ReadFile("internal/i18n/catalog_" + lang + ".go")
	if err != nil {
		return err
	}
	var b strings.Builder
	b.WriteString(headers[lang] + "\n")
	n := 0
	for _, line := range strings.Split(string(body), "\n") {
		m := entryRe.FindStringSubmatch(line)
		if m == nil {
			continue
		}
		key, ok := keys[m[1]]
		if !ok {
			return fmt.Errorf("%s: msgid.%s is not declared in internal/msgid", lang, m[1])
		}
		if m[2] != "" {
			key += keys["PluralOneSuffix"]
		}
		text, err := strconv.Unquote(m[3])
		if err != nil {
			return fmt.Errorf("%s: %s: %w", lang, key, err)
		}
		quoted := strconv.Quote(text)
		// strconv.Quote 的转义里，YAML 双引号不认的只有 \x.. 与 \U........：遇到就停，别写出读不回来的文件
		if strings.Contains(quoted, `\x`) || strings.Contains(quoted, `\U`) {
			return fmt.Errorf("%s: %s: text needs an escape YAML can't read: %s", lang, key, quoted)
		}
		fmt.Fprintf(&b, "%s: %s\n", key, quoted)
		n++
	}
	if err := os.MkdirAll("internal/i18n/locales", 0o755); err != nil {
		return err
	}
	if err := os.WriteFile("internal/i18n/locales/"+lang+".yaml", []byte(b.String()), 0o644); err != nil {
		return err
	}
	fmt.Printf("%s: %d entries\n", lang, n)
	return nil
}
```

```go
// Package msgidgen 从源语言目录生成 internal/msgid 的消息常量。只在构建期用（cmd/gen-msgid、
// 检查测试、tools/i18n），CLI 运行时不引用它。
package msgidgen

import (
	"bytes"
	"fmt"
	"go/format"
	"os"
	"strings"

	"gopkg.in/yaml.v3"
)

// initialisms 是写成全大写的词（Go 的惯例：ID、JSON、URL……）。
var initialisms = map[string]bool{
	"id": true, "json": true, "yaml": true, "url": true, "http": true, "https": true, "api": true, "dns": true,
	"tls": true, "cpu": true, "io": true, "sa": true, "pr": true, "ci": true, "ui": true, "uid": true, "pid": true,
	"tcp": true, "udp": true, "ssh": true, "oci": true,
}

// GoName 是 key 对应的常量名：按 . 与 _ 切开，每段首字母大写，缩写词全大写。
func GoName(key string) string {
	var b strings.Builder
	for _, part := range strings.FieldsFunc(key, func(r rune) bool { return r == '.' || r == '_' }) {
		if initialisms[part] {
			b.WriteString(strings.ToUpper(part))
			continue
		}
		b.WriteString(strings.ToUpper(part[:1]) + part[1:])
	}
	return b.String()
}

// SourceKeys 按文件顺序读出目录文件里的 key。
func SourceKeys(path string) ([]string, error) {
	data, err := os.ReadFile(path)
	if err != nil {
		return nil, err
	}
	var doc yaml.Node
	if err := yaml.Unmarshal(data, &doc); err != nil {
		return nil, fmt.Errorf("%s: %w", path, err)
	}
	if len(doc.Content) == 0 || doc.Content[0].Kind != yaml.MappingNode {
		return nil, fmt.Errorf("%s: not a mapping of key: text", path)
	}
	root := doc.Content[0]
	keys := make([]string, 0, len(root.Content)/2)
	for i := 0; i+1 < len(root.Content); i += 2 {
		keys = append(keys, root.Content[i].Value)
	}
	return keys, nil
}

const pluralOneSuffix = ".one" // 与 msgid.PluralOneSuffix 相同；msgidgen 不引用 msgid，免得生成器依赖被生成的包

// Render 生成 messages_gen.go 的源码。
func Render(keys []string) ([]byte, error) {
	var b bytes.Buffer
	b.WriteString("// Code generated by cmd/gen-msgid; DO NOT EDIT.\n")
	b.WriteString("// 源：internal/i18n/locales/en.yaml。增删消息改目录，再跑 make generate-msgid。\n\n")
	b.WriteString("package msgid\n\nconst (\n")
	owner := map[string]string{}
	for _, key := range keys {
		if strings.HasSuffix(key, pluralOneSuffix) {
			continue
		}
		name := GoName(key)
		if prev, dup := owner[name]; dup {
			return nil, fmt.Errorf("keys %q and %q both become the Go name %s", prev, key, name)
		}
		owner[name] = key
		fmt.Fprintf(&b, "\t%s = %q\n", name, key)
	}
	b.WriteString(")\n")
	return format.Source(b.Bytes())
}
```

```go
// rekey：给消息 ID 改名——同时改代码里的 msgid.X 与每份目录里的 key，文案一个字节不动。
//
//	go run ./tools/i18n/rekey -drift            列出名字可能与文案对不上的 key（审阅用，不做决定）
//	go run ./tools/i18n/rekey -apply renames.tsv 按 "旧key<TAB>新key" 改名；任何一条通不过校验就什么都不写
package main

import (
	"bufio"
	"flag"
	"fmt"
	"go/ast"
	"go/format"
	"go/parser"
	"go/token"
	"io/fs"
	"os"
	"path/filepath"
	"regexp"
	"sort"
	"strings"

	"github.com/brickkit/brickkit/internal/msgid/msgidgen"
)

type rename struct{ Old, New string }

var keyLineRe = regexp.MustCompile(`^([a-z0-9_.]+):`)

// apply 先整批校验，再改写：旧 key 都存在、新 key 都不存在、改名后 Go 名字不撞。
func apply(root string, renames []rename) error {
	enPath := filepath.Join(root, "internal/i18n/locales/en.yaml")
	keys, err := msgidgen.SourceKeys(enPath)
	if err != nil {
		return err
	}
	exists := map[string]bool{}
	for _, k := range keys {
		exists[k] = true
	}
	byOld := map[string]string{}
	for _, r := range renames {
		if !exists[r.Old] {
			return fmt.Errorf("%s: no such key", r.Old)
		}
		if exists[r.New] {
			return fmt.Errorf("%s: key already exists", r.New)
		}
		byOld[r.Old] = r.New
	}
	after := make([]string, len(keys))
	for i, k := range keys {
		if n, ok := byOld[k]; ok {
			k = n
		}
		after[i] = k
	}
	if _, err := msgidgen.Render(after); err != nil {
		return err // 改名后两个 key 推出同一个 Go 名字
	}
	names := map[string]string{} // 旧 Go 名 → 新 Go 名
	for o, n := range byOld {
		names[msgidgen.GoName(o)] = msgidgen.GoName(n)
	}

	pending := map[string][]byte{} // 全部算完再写，写之前任何一步失败都不留半成品
	locales, _ := filepath.Glob(filepath.Join(root, "internal/i18n/locales", "*.yaml"))
	for _, f := range locales {
		out, err := renameKeys(f, byOld)
		if err != nil {
			return err
		}
		pending[f] = out
	}
	for _, dir := range []string{"internal", "cmd", "tests", "tools", "market-server"} {
		err := filepath.WalkDir(filepath.Join(root, dir), func(path string, d fs.DirEntry, err error) error {
			if err != nil {
				if os.IsNotExist(err) {
					return filepath.SkipDir
				}
				return err
			}
			if d.IsDir() || !strings.HasSuffix(path, ".go") {
				return nil
			}
			out, changed, err := renameSelectors(path, names)
			if err != nil {
				return err
			}
			if changed {
				pending[path] = out
			}
			return nil
		})
		if err != nil {
			return err
		}
	}
	for path, out := range pending {
		if err := os.WriteFile(path, out, 0o644); err != nil {
			return err
		}
	}
	return nil
}

// renameKeys 只改行首的 key，冒号之后原样保留。
func renameKeys(path string, byOld map[string]string) ([]byte, error) {
	body, err := os.ReadFile(path)
	if err != nil {
		return nil, err
	}
	lines := strings.SplitAfter(string(body), "\n")
	for i, line := range lines {
		if m := keyLineRe.FindStringSubmatch(line); m != nil {
			if n, ok := byOld[m[1]]; ok {
				lines[i] = n + line[len(m[1]):]
			}
		}
	}
	return []byte(strings.Join(lines, "")), nil
}

// renameSelectors 把 msgid.<旧名> 换成 msgid.<新名>，按 AST 位置改，不做文本搜索。
func renameSelectors(path string, names map[string]string) ([]byte, bool, error) {
	src, err := os.ReadFile(path)
	if err != nil {
		return nil, false, err
	}
	fset := token.NewFileSet()
	f, err := parser.ParseFile(fset, path, src, parser.ParseComments)
	if err != nil {
		return nil, false, err
	}
	type edit struct {
		off  int
		old  string
		name string
	}
	var edits []edit
	ast.Inspect(f, func(n ast.Node) bool {
		sel, ok := n.(*ast.SelectorExpr)
		if !ok {
			return true
		}
		if id, ok := sel.X.(*ast.Ident); ok && id.Name == "msgid" {
			if nn, ok := names[sel.Sel.Name]; ok {
				edits = append(edits, edit{fset.Position(sel.Sel.Pos()).Offset, sel.Sel.Name, nn})
			}
		}
		return true
	})
	if len(edits) == 0 {
		return src, false, nil
	}
	sort.Slice(edits, func(i, j int) bool { return edits[i].off > edits[j].off })
	out := string(src)
	for _, e := range edits {
		out = out[:e.off] + e.name + out[e.off+len(e.old):]
	}
	formatted, err := format.Source([]byte(out))
	return formatted, true, err
}
```

```go
var verbWithTypeRE = regexp.MustCompile(`%[-+# 0]*\d*(?:\.\d+)?\[(\d+)\]([a-zA-Z])`)

// verbSet：%[2]d → "2d"，去重排序——位置与类型都要对上。
func verbSet(tmpl string) []string {
	seen := map[string]bool{}
	for _, m := range verbWithTypeRE.FindAllStringSubmatch(tmpl, -1) {
		seen[m[1]+m[2]] = true
	}
	out := make([]string, 0, len(seen))
	for v := range seen {
		out = append(out, v)
	}
	sort.Strings(out)
	return out
}
```
