# 09 · 组件市场

🎯 **这一节验证什么：** 把市场后端跑起来，登录、发布一个组件、再从市场把它装回来。

前置：Docker 可用。这一节独立于 05–08，随时可以做。

---

## 9.1 起市场后端

市场是一套独立的服务：**市场服务 + PostgreSQL + RustFS（S3 兼容对象存储）**。

### ▶️ 操作

```bash
cd deploy/market
cp .env.example .env
vi .env                     # 至少填 POSTGRES_PASSWORD / RUSTFS_SECRET_KEY / ADMIN_PASSWORD
docker compose up -d
```

等它起来：

```bash
docker compose ps
curl http://localhost:8080/api/v1/health
```

### ✅ 预期

`health` 返回 200。三个容器都 healthy。

> **`.env` 必须和 `docker-compose.yaml` 同目录** —— docker compose 只读项目目录（默认就是 compose 文件所在目录）下的 `.env`。这一点和 BrickKit 项目不一样：那边 CLI 会显式传 `--project-directory`，把项目根的 `.env` 喂给 compose。

---

## 9.2 登录

### ▶️ 操作

```bash
cd <你的 BrickKit 项目目录>
brickkit login --market http://localhost:8080/api/v1 --username admin
```

会交互式问密码（不回显）。CI 里用：

```bash
echo "$PASSWORD" | brickkit login --market ... --username admin --password-stdin
```

### ✅ 预期

Token 存进 `.brickkit/credentials`（`.gitignore` 已忽略）。Token 过期后 CLI 会明确提示重新登录，而不是给一句看不懂的 401。

---

## 9.3 发布一个组件

### ▶️ 操作

```bash
cd 试用指南/playground/components/demo/hello
brickkit publish --market http://localhost:8080/api/v1 \
                 --changelog "第一次发布" \
                 --visibility public \
                 --source-type registry
```

`--path` 默认是当前目录（要有 `component.yaml`）。

### ✅ 预期

发布前市场会做**源头校验**，这几类会被直接拒绝：

| 拒绝原因 | 为什么 |
| --- | --- |
| `configSchema` 里用了平台保留变量（`COMPONENT_ID`、`DATABASE_*` 等） | 注入时会撞车。市场是第一道闸，CLI 是最后一道 |
| 闭源组件（`source-type: registry`）没提供 API 契约产物 | 别人拿不到契约就没法对接 |
| 同一个版本重复发布 | 版本是不可变的 |

---

## 9.4 从市场装回来

### ▶️ 操作

在一个新项目里，把市场配成安装源：

```yaml
sources:
  - id: brickkit-market
    type: market
    url: http://localhost:8080/api/v1
    # authToken: ${MARKET_TOKEN}    # 也可以不写：已 login 的话 CLI 用登录态
    enabled: true

  - id: local-dev
    type: local
    path: ./components
    enabled: true
```

```bash
brickkit add demo/hello@1.0.0
```

### ✅ 预期

多个源按**声明顺序**依次尝试。市场里没有就试下一个源；两个源都没有才报"组件未找到"，并列出**试过哪些源**。

被下架（blocked）的版本会给出"该版本已被市场下架"，而不是笼统的"认证失败，请登录"。

---

## ⏹️ 怎么停

```bash
cd deploy/market
docker compose down            # 停掉市场，数据保留在 ./data/
docker compose down -v         # 连数据一起删
```

登出（删掉本地 Token）：

```bash
rm .brickkit/credentials
```
