## 走之前先知道三件事

这三件是走这条线时最容易卡住的地方，先说在前面。

### ① 组件目录必须是 `<scope>/<name>`

本地安装源靠这个布局定位组件。放成 `demo-hello` 的话，
`brickkit add demo/hello` 会说找不到。

### ② `brickkit init` 生成的骨架里**没有** `sources`

要自己补一段，否则 `add` 会报"没有可用的安装源"：

```yaml
sources:
  - id: local-dev
    type: local
    path: ./components
```

### ③ CLI 不替你建数据库

12 那一篇第一次 `up` **会失败**，而且是故意的：

```
📌 以下数据库需要预先创建（平台不代建，见 006 §9.5）：
   erp_auth  （postgres:5432，供 auth/password-login 使用）
      CREATE DATABASE "erp_auth";
```

建库要 `CREATEDB` 权限，云数据库上应用账号通常没有——代建会造成
"开发能跑、生产必炸"。所以库由人建，库名由平台注入。
