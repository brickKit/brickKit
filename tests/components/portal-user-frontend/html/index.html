这个页面是静态资源，由 nginx 直接发出。下面所有请求都走 /api/，由 nginx 反向代理到 erp/backend—— 浏览器从头到尾只认识门户这一个地址，后端在哪由平台注入 ${ERP_BACKEND_ENDPOINT} 决定。
