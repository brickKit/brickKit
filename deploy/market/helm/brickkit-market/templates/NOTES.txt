BrickKit 组件市场已部署：{{ .Release.Name }}（命名空间 {{ .Release.Namespace }}）

1) 等它起来
   kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "market.fullname" . }}

   首次启动要建表、建 bucket，比平时慢——startupProbe 给了 60 秒。

2) 确认健康
{{- if .Values.ingress.enabled }}
   curl http://{{ .Values.ingress.host }}/api/v1/health
{{- else }}
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "market.fullname" . }} 8080:{{ .Values.service.port }}
   curl http://localhost:8080/api/v1/health
{{- end }}

3) 在项目里连它
   sources:
     - id: brickkit-market
       type: market
       url: {{ if .Values.ingress.enabled }}http://{{ .Values.ingress.host }}/api/v1{{ else }}http://<你的入口>/api/v1{{ end }}

{{- if .Values.deps.enabled }}

⚠️  deps.enabled=true：PostgreSQL 与对象存储跑在集群里，**仅供评估**。
    生产请关掉它，把 database / storage 指向云托管实例——
    备份、主从、版本升级这些事，一个 StatefulSet 替不了。
{{- end }}
{{- if not .Values.auth.existingSecret }}

⚠️  口令是通过 --set 传进来的，它们会留在 Helm 的 release 记录里
    （集群中的 sh.helm.release.v1.* Secret）。生产请改用：
      auth.existingSecret=<你自己创建并轮换的 Secret 名>
{{- end }}
{{- if .Values.market.adminPasswordReset }}

⚠️  adminPasswordReset=true：**每次重启都会重置 admin 口令**。
    用完请改回 false 再 helm upgrade。
{{- end }}
